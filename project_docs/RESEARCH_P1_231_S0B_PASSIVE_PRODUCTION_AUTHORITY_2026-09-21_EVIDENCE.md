## Execution contract

The production verifier maps the only supported runtime profile to exact CPython `3.12.10`.

The default executor:

1. verifies actual CPython implementation/version;
2. materializes exact generator/input Git blob bytes in a new temporary root;
3. does not materialize committed outputs before execution;
4. runs the declared generator with bounded timeout/output and a bounded environment;
5. rejects mutation of declared generator/input bytes;
6. requires all declared outputs;
7. rejects undeclared generated files;
8. compares generated bytes exactly with committed output Git blobs;
9. destroys the temporary workspace.

Any byte mismatch fails with `STALE_GENERATED_OUTPUT`.

The authority returns only passive verification state:

- `policy_mutation=false`
- `artifact_build=false`
