# Индекс recovery-документации

Рекомендуемый порядок чтения:

1. `PROJECT_OVERVIEW.md` — что это за проект и его инварианты.
2. `USER_REQUIREMENTS.md` — требования пользователя.
3. `ARCHITECTURE.md` — компоненты и потоки.
4. `DECISIONS_AND_RATIONALE.md` — почему архитектура именно такая.
5. `CHANGELOG_AND_RATIONALE.md` — история функционала.
6. `PRIORITIES_P0_P1_P2.md` — что критично и что дальше.
7. `DATA_MODELS.md` — IndexedDB/storage/snapshot.
8. `ASSISTANT_NOTES_AND_LIMITATIONS.md` — технические ограничения.
9. `TEST_PLAN.md` — регрессионные проверки.
10. `BUILD_AND_RECOVERY_RULES.md` — как выпускать следующую версию.
11. `RESTORE_PROMPT.md` — быстрый старт в новом чате.

- `GITHUB_WORKFLOW.md` — canonical private remote и правила синхронизации GitHub/handoff.
