# Research evidence ledger

This document consolidates unique implementation/browser evidence from historical root `P*_CLOSURE.md` checkpoints.

It is **evidence**, not a statement that every listed P-item is currently closed. Later research deltas and the current registry may reopen or refine an item. The authoritative current status comes from `project_docs/PRIORITIES_P0_P1_P2.md`, `project_docs/RESEARCH_CONSOLIDATION_INDEX.md`, current `RESEARCH_DELTA_*` evidence and current source.

No tests were rerun to produce this document. All PASS counts and browser results below are historical results copied from their recorded closure checkpoint.

## Interpretation rules

- **Historical gate** = what the project proved at that implementation checkpoint.
- **Current caveat** = known later research evidence that prevents treating the old gate as current full closure.
- All historical gates below used Manifest V3 / version `0.9.8` unless explicitly noted otherwise.
- Managed Chromium/browser evidence is valuable regression evidence but is not the required final unpacked Chrome + real Yandex release QA.
- Exact detailed contracts remain in the referenced closure/delta files until their individual retirement research is complete.

## Closure-file retirement status

This ledger is the first migration pass. **No root `P*_CLOSURE.md` is declared safe to delete yet.**

Before retiring an individual closure file:

1. compare its complete content with this ledger and the current P-owner registry;
2. ensure every unique implementation fact, browser observation, numeric bound, test identity, reopen note and release-QA limitation is represented here or another canonical evidence document;
3. ensure current docs do not link to that closure as the only evidence source;
4. then remove that closure in a dedicated docs/history cleanup commit and verify no runtime/test/config changes.

Once the retirement comparison is complete, Git history becomes the archive for the verbose original closure narrative.
