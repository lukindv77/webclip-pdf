# Приоритеты P0 / P1 / P2 — WebClip 0.9.9 WIP

Статусы: `DONE` — реализовано и закрыто подтверждённой проверкой; `REGRESSION` — исправление реализовано и прошло локальные проверки, но обязательно остаётся в реальном regression QA; `PARTIAL` — исправлена только часть задачи; `OPEN` — требует реализации/проверки; `AUDIT` — найдено аудитом и классифицировано, исправление ещё не подтверждено повторным проходом.

Коды вида `P0-001`, `P1-001`, `P2-001` являются **стабильными и уникальными**. После назначения код не меняется при смене статуса и не переиспользуется для другой задачи.

| Код | Приоритет | Статус | Пункт |

| P1-003 | P1 | REGRESSION | Перед PDF выполняется bounded prefetch ресурсов выбранного контента: common lazy `img/source[data-src|data-srcset]` временно активируются, `loading=lazy` переводится в eager с rollback после print, CSS `background-image` прогревается через renderer `Image`, используемые font specs — через `document.fonts.load`. | P1-006 | P1 | REGRESSION | Проверка соответствия PDF retry cache текущему URL при навигации той же вкладки. Реализация усилена аудитом в `P0-023`: URL + TTL + invalidation при навигации. |
| P1-007 | P1 | REGRESSION | Автоматизированные browser integration tests: policy-safe Chromium runner выполняет реальные `content.js` selection + selected-only PDF render, реальный `journal.js` через runtime fallback и реальный `service-worker.js` в browser Worker с mocked `chrome.*`/Yandex fetch; отдельный unpacked MV3 runner использует `Extensions.loadUnpacked` для Chrome for Testing/обычного Chrome. Managed Chromium 144 gate PASS; unpacked E2E остаётся release QA. |
| P1-008 | P1 | REGRESSION | Экспорт/импорт `webclip-user-settings` v1 переносит только allowlist пользовательских настроек: Yandex `clientId/rootPath/createPublicLinks`, background backup interval/retry/enabled, Journal `groupByUrl`, OperationLog retention. Импорт строго валидирует schema/size/types, выполняет один bundled `chrome.storage.local.set` с durable reconciliation marker; unknown settlement не ретраится автоматически и восстанавливает scheduler при следующем MV3 worker start. Chromium Options regression PASS; manifest остаётся `0.9.8`. |
| P1-009 | P1 | REGRESSION | Универсальный многострочный фильтр журнала реализован поверх bounded cursor architecture: до 8 строк по 512 символов, поля `Наименование` (по умолчанию), `Комментарии` (комментарий к файлу + пользовательские комментарии журнала), `Сайт`, `URL`, логика `И` по умолчанию / `ИЛИ`.
