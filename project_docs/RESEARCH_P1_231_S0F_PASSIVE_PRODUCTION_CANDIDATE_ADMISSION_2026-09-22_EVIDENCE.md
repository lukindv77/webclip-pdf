## Authority composition

S0-F owns no new identity axis.

For one exact 40-hex candidate commit it composes:

- S0-A exact package admission;
- S0-B exact source-generation verification;
- S0-C generator-governance binding;
- S0-E current identity tuple.

The gate first normalizes and resolves the exact candidate through S0-A.

It then requires every declared S0-B generator path to be a current S0-C full-RCF root. The current `project_tools/build_public_suffix_js.py` relation therefore remains governed by the same full-RCF generation that supplies the candidate identity.

After that, S0-B regenerates declared outputs and requires exact byte equality with committed candidate outputs.

Finally, S0-E computes the candidate's exact:

- RPF;
- per-kind QCF;
- full RCF;
- BCF.

All components must refer to the same exact candidate SHA.

## Result contract

Schema:

`webclip-candidate-generation-result/v1`

Successful passive admission reports:

- exact `candidate_sha`;
- `generation_state=pass`;
- canonical package-member count;
- relation/runtime/generator/input/output digests;
- `generator_rcf_binding=bound`;
- current RPF/QCF/RCF/BCF tuple.

It explicitly reports:

- `policy_mutation=false`
- `receipt_interpretation=false`
- `evidence_settlement=false`
- `artifact_build=false`
- `release_authorized=false`

There is deliberately **no candidate-generation fingerprint / CGF axis**.

Candidate SHA remains the orchestration identity. RPF equality across two commits does not permit one candidate result to authorize another SHA.

## Fail-closed boundaries

Admission fails on at least:

- moving/non-40-hex candidate refs;
- missing/non-regular package or generation Git objects;
- source-generation runtime-profile mismatch;
- missing/extra generated outputs;
- stale generated bytes;
- generator not present in current full-RCF roots;
- malformed/mismatched S0-E identity result;
- result consumption against a different candidate SHA.

A computable RPF does not override stale generation.

A successful generation result is not a QA receipt and does not imply release readiness.
